# Clinic Management System — SQL Server

## About the Project
A database project designed to manage clinic operations, including doctors, patients, appointments, medical visits, prescriptions, medicines, and payments.

## Technologies
- Microsoft SQL Server
- SQL

## Database Design
- Entity Relationship Diagram (ERD)
- Mapping
- Database Normalization
- Tables, Primary Keys, Foreign Keys, and Constraints

## SQL Concepts Implemented
- CRUD Operations
- Joins and Aggregate Functions
- Subqueries, EXISTS, CTEs, and CASE
- Views
- Scalar and Table-Valued Functions
- Stored Procedures
- Triggers
- Data validation and business rules

## Project Structure
- `01-Database-Design`: ERD, mapping, and normalization
- `02-Database-Creation`: Database and table creation scripts
- `03-Sample-Data`: Sample data insertion scripts
- `04-Queries`: SQL queries and practice tasks
- `05-Database-Objects`: Views, functions, procedures, and triggers
- `06-Screenshots`: Selected screenshots of the project

## How to Run
1. Open SQL Server Management Studio (SSMS).
2. Execute the database creation script.
3. Execute the sample data script.
4. Run the query and database object scripts in the appropriate order.

## Purpose
This project was created to strengthen my practical SQL Server skills and understand how database design and SQL concepts work together in a real-world scenario.
